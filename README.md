# Phrase — 100 выражений для памяти

Личное приложение для iPhone, iPad и компьютера. Постоянная ссылка: https://evgk724.github.io/phrase-100/

**50 фразовых глаголов + 50 коллокаций, 20 тем, 200 примеров и заданий, 326 записей Microsoft Ryan.** Тёмная графитовая тема, спокойные тёмные кнопки, основной шрифт 18 px с настройками 20 и 22.

## Содержание

Практическая сотня частых выражений для перехода B1 → B2. Сначала повседневное общение и учёба, затем отношения, планы, проблемы, рабочая речь, чтение и обсуждение исследований. Номера обозначают учебный порядок, а не точный корпусный рейтинг. Уровень относится к сложности урока и практики: знакомая базовая лексика также закрепляется в более развёрнутых фразах.

Каждая тема содержит пять выражений, десять авторских примеров, короткое объяснение, опоры для памяти и тренировку на десять заданий. У многозначных глаголов сначала отрабатывается один выбранный смысл; другие частые значения отмечены в пояснениях. При классификации используются привычные для учебных материалов группы phrasal / multi-word verbs.

Каталог ищет по английскому выражению и русскому смыслу; фильтры: фразовые глаголы / коллокации и этап курса. У каждой записи есть объяснение, подсказка, сведения о порядке слов, два примера с озвучкой и переход к тренировке своей пятёрки.

## Активное вспоминание

Карточки показываются по пять, всего двадцать страниц. Два направления: русский → английский для активной речи; английский → русский для понимания. Ответ изначально скрыт; кнопка доступна с клавиатуры. После раскрытия — Ryan, образ для памяти и пояснение. Просмотр карточек не оценивается автоматически; интервалы меняются после оценённого ответа в тренировке.

Практика включает выбор выражения, ввод без вариантов, исправление, понимание смысла в английском контексте, аудирование и устное восстановление с самооценкой. В режиме понимания русский перевод до ответа скрыт. Варианты выбора перемешиваются. Ввод и исправление ориентированы на изучаемые выражения; нужно сохранять остальные слова исходного предложения. Устный режим не распознаёт и не записывает речь.

Принимаются подготовленные нормальные варианты: take / have a shower, take / make notes, make / take a decision, do / conduct / carry out research и другие. Для ряда разделяемых глаголов принимается перенос существительного внутрь. Местоимения проверяются отдельно: turn it off, а не turn off it.

## Повторения и ошибки

Базовые интервалы: 1, 3, 7, 14, 30, 60, 120, 180 дней. «Легко» пропускает ступень; «С трудом» сокращает срок. Ошибка возвращается после нескольких других заданий, а ближе к концу занятия — раньше; не более одного раза за занятие. Ошибка назначается через 10 минут, успешное исправление в том же занятии — на следующий день. Дополнительная ранняя практика не увеличивает интервал искусственно.

«Сегодня» сначала показывает повторения, затем новое по порядку. Личная ошибка уходит из списка после успешных ответов в два разных последующих дня. Это прозрачная адаптация по ответам, без обещания индивидуально оптимальных интервалов.

## Установка и офлайн

1. Откройте постоянную ссылку в Safari.
2. «Поделиться» → «На экран “Домой”» → «Добавить».
3. Если доступно «Открывать как веб-приложение», включите этот переключатель.
4. Начинайте занятия из иконки **Phrase**.

В настройках: **«Сохранить уроки и аудио»**. Оставьте приложение открытым до завершения. После сохранения уроки, тренировки и все 326 записей доступны без интернета. iOS может освобождать кэш при нехватке места.

Голос — **en-GB-RyanNeural**, британский английский, исходный темп немного замедлен. Скорость воспроизведения: 0,8× / 1× / 1,15×. Голос устройства не подставляется вместо Ryan.

## Данные

Прогресс, ошибки и настройки остаются на устройстве. Автоматической синхронизации iPhone/iPad нет. В настройках можно сохранить JSON и восстановить его на другом устройстве после подтверждения замены. Удаление данных сайта удаляет локальный прогресс; Safari и приложение с иконки могут иметь отдельные хранилища. Резервные копии Tense, Article и Verb не импортируются в Phrase.

## Разработка и проверка

Статическое приложение без сборки и внешних библиотек в рабочем интерфейсе. HTML/CSS/ES modules, JSON и MP3. Без аккаунта, рекламы и аналитики. Запускайте через HTTP(S), не двойным нажатием на HTML.

`node --test tests/engine.test.mjs tests/sw.test.cjs` — состав курса, допустимые ответы, порядок слов, повторы, сохранение, аудио, service worker и Range для Safari.

`node tests/browser.cjs` — Chromium; `QA_BROWSER=webkit node tests/browser.cjs` — WebKit. Нужны Playwright 1.62.1 и соответствующий браузер. Можно задать WEBKIT_PATH для локального WebKit. Проверяются экран телефона/планшета, размеры 18/22, все сто карточек и раскрытие с клавиатуры, фильтры каталога, занятия, ошибки, альтернативные ответы, сохранение/восстановление, реальное воспроизведение MP3 и офлайн. CI запускает оба браузера.

Изоляция: `phrase-progress-v1`, `phrase-shell-*`, `phrase-audio-v1`, область service worker `/phrase-100/`. Другие учебные приложения не используют эти ключи.
